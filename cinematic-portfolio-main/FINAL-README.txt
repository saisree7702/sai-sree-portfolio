# Sai Sree — Final Portfolio

This ZIP contains the customized React/Vite portfolio.

## Projects included
- **WorkNest.Com** — links to the RTRP GitHub repository: https://github.com/saisree7702/RTRP
- **MediSearch** — links to the MediSearch GitHub repository: https://github.com/saisree7702/MediSearch
- **AgriAssist AI** — UI/design completed; implementation in progress. No GitHub button is shown until the project is completed and uploaded.

## Run locally
1. Extract this ZIP.
2. Open the `cinematic-portfolio-main` folder in VS Code.
3. In the terminal, run `npm install` (only if needed).
4. Run `npm run dev` and open the Local URL printed in the terminal.

The project uses Vite, React, TypeScript, Tailwind CSS, and Framer Motion. Existing portfolio sections, assets, resume file, and scroll animations are retained.
